
# Staark — Tillgängliga teman

En samling färdiga teman för Staark-projekt.

Temana är tänkta som startpunkter för nya kundprojekt och kan anpassas med kundens färger, innehåll, logotyp, bilder och funktioner.

> **4 teman finns tillgängliga just nu.** Fler teman läggs till löpande.

# 🖼️ Preview-bilder

För att göra temakatalogen enklare att överblicka rekommenderas en preview-bild för varje tema.

```text
avaible-themes/
├── previews/

│   ├── s-hub-skonhet.webp

├── s-hub-hantverk.zip
├── s-hub-skonhet.zip
├── s-hub-verkstad.zip
└── index.md
```

När bilderna finns kan de visas direkt i katalogen:

```md
### ⚡ El

![El Theme Preview](./previews/s-hub-el.webp)
```

# ➕ Lägg till ett nytt tema

När ett nytt tema läggs till:

1. Lägg ZIP-filen i `avaible-themes/`.
2. Använd namngivning enligt:

```text
s-hub-<kategori>.zip
```

3. Lägg till en preview-bild i:

```text
avaible-themes/previews/
```

4. Lägg till temat i tabellen högst upp.
5. Lägg till en kort beskrivning.
6. Lägg till download-länk.
